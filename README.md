Sports Card Market Intelligence Dashboard

An interactive sports card market analytics dashboard designed to analyze pricing trends, high-value transactions, market activity, and raw-to-graded price differences.

Overview

This project explores sports card marketplace data to identify pricing patterns, high-value sales, and changes in card values across different players, sports, and card variations.

The dashboard combines data analysis, visualization, and interactive filtering to make market information easier to explore and interpret.

Analysis

The dashboard focuses on several areas:

High-Value Sales

Tracks notable marketplace transactions and compares observed sale prices across cards and players.

Price Movement

Visualizes observed transaction prices over time to identify changes in market value and pricing ranges.

Market Comparison

Compares cards across sports, players, variations, and grading levels to identify differences in market behavior.

Raw-to-Graded Analysis

Examines the potential change in market value when a raw card receives different professional grading outcomes.

Data Methodology

The project uses marketplace transaction data and structured card information to create comparable observations.

Data is organized by:

Player
Sport
Card
Card variation
Grade
Sale date
Sale price

Transactions are evaluated individually rather than treating every version of a player's card as the same asset.

This helps reduce misleading comparisons between base cards, parallels, numbered cards, and graded versions.
