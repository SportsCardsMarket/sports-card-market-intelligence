# Sports Card Market Intelligence

Portfolio-ready sports-card transaction analytics dashboard designed as a multi-sport market terminal.

## Current modules
- Market Terminal overview
- 50-card research universe
- Searchable card universe
- Individual clickable card market profiles
- Sales Tape for completed transactions
- Market Movers with sample-aware recent-vs-earlier comparisons
- Card Compare for side-by-side transaction analysis
- Market Reports / Market Pulse
- Automated The Card API refresh pipeline
- GitHub Pages deployment
- Clear distinction between verified completed sales and pending/unavailable data

## Data integrity
The card catalog is a research universe, not a claim that every card has live pricing. Observed prices are only shown when transaction data is actually loaded. No missing transaction values are fabricated.

## Portfolio framing
This project demonstrates data ingestion, API integration, ETL normalization, scheduled automation, statistical summaries, filtering, interactive dashboards and static web deployment.
