Transaction source

The production feed uses The Card API's completed-sale endpoint. Its documented schema includes sale price, sale date, platform, listing type, grade and listing URL. citeturn1search1

Analytics

The dashboard calculates medians, averages, ranges, transaction volume, liquidity and recent-vs-earlier movement from the returned observations. No price is invented when the sample is empty.

Market discipline

Low sample sizes are explicitly labeled. Asking prices are not mixed with completed sales, and historical observations are not presented as guaranteed future values.

Data architecture

The Card API → GitHub Actions → Python normalization → JSON dataset → GitHub Pages dashboard. The API supports cursor pagination and daily sales feeds; paid plans provide longer lookback windows and persistent-data use cases. citeturn1search1turn1search0
